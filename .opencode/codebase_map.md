# Architecture

Next.js 15 App Router, TypeScript, React 18. `app/page.tsx` compose le portfolio et ses données structurées. `app/layout.tsx` porte metadata, fonts et styles. `lib/data.ts` centralise contenu, six projets, services, FAQ et contacts. `components/Contact.tsx` prépare un mailto sans backend ; aucun envoi serveur. `app/robots.ts`, `app/sitemap.ts`, `app/llms.txt/route.ts`, `app/manifest.ts`, icônes et opengraph préservent SEO/GEO. Styles globaux dans `app/globals.css`. Production : https://www.danhabib.dev, GitHub danhab05/danhabibtech.
