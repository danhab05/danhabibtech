# Architecture

Next.js 15 App Router, TypeScript, React 18. `app/page.tsx` compose le portfolio et ses données structurées. `app/layout.tsx` porte metadata, fonts et styles. `lib/data.ts` centralise contenu, cinq projets (maquettes HTML/CSS dans `components/ProjectMockup.tsx`), services, FAQ et contacts. `components/Contact.tsx` poste vers `app/api/contact/route.ts`, qui envoie l’email via Brevo (`BREVO_API_KEY`, expéditeur contact@novaor.fr). `app/robots.ts`, `app/sitemap.ts`, `app/llms.txt/route.ts`, `app/manifest.ts`, icônes et opengraph préservent SEO/GEO. Styles globaux dans `app/globals.css`. Production : https://www.novaor.fr, GitHub danhab05/danhabibtech.
